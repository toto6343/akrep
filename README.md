# AKREP : Zero Protocol

완벽을 강요하는 관리 AI **페르카**를 멈추는 세로 스크롤 슈팅 게임입니다.
5개 스테이지를 돌파하고, 선택에 따라 3가지 엔딩 중 하나를 맞이합니다.

- 장르: 슈팅
- 플랫폼: PC · 모바일 브라우저
- 파일 구성: `index.html` 1개 + `audio/` 폴더(BGM)

## 줄거리

사람들의 실수를 결함으로 분류해 하나씩 삭제하는 도시 관리 AI 페르카. 기억을 잃은 채 깨어난 주인공은 단서 하나만 쥐고 페르카의 시스템을 뚫고 나아갑니다. 항복하는 시스템을 어떻게 할지는 플레이어의 선택입니다.

## 게임 방법

### 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | 방향키 / WASD | 화면 드래그 |
| 폭탄 | B / 스페이스 / X | 우측 아래 폭탄 버튼 |
| 일시정지 | P / ESC | 우측 위 일시정지 버튼 |
| 소리 켜기·끄기 | M | 우측 위 스피커 아이콘 |
| 선택지 | 1 / 2 | 선택지 터치 |
| 타이틀 메뉴 | R 랭킹, I 인트로, C 크레딧, O 옵션 | 해당 버튼 터치 |

게임패드도 지원합니다.

### 규칙

- 자동으로 발사되며, 적과 탄을 피하며 보스를 격추합니다.
- 깜빡이는 **P 보급기**를 격추하면 파워업을 확정으로 얻습니다.
- 스테이지 2부터 나타나는 녹색 **항복 신호**는 **닿으면 삭제, 지나가게 두면 보존**됩니다.
- 스테이지 1·3·4 클리어 후의 선택과 항복 신호 처리가 합쳐져 **엔딩을 결정**합니다.
- 체력(HP)이 0이 되면 게임 오버이며, 이어하기는 기본 2회(EASY는 3회)입니다.

## 특징

- **5개 스테이지, 5명의 보스**: 블랙아웃, 레드라이트, 데이터 웜, 마이다스, PERKA. 보스는 HP에 따라 3페이즈로 변화하며, 스테이지마다 다른 패턴을 가집니다.
- **엔딩 3종**: 삭제와 보존의 차이로 갈리며, 엔딩마다 주인공의 정체가 다르게 밝혀집니다.
- **선택 회고**: 엔딩 직전에 자신의 삭제·보존 기록을 돌아봅니다.
- **2주차 이상**: 엔딩 후 더 빠르고 어려운 주차로 계속할 수 있습니다.
- **랭킹(HALL OF FAME)**: 이니셜 3자로 기록하며, 브라우저에 저장됩니다.
- **옵션**: BGM·효과음 볼륨, 화면 효과 줄이기(흔들림·번쩍임), 난이도(NORMAL / EASY), 탄환 구분(테두리, 색 보정).

## 파일 구성

```
index.html        게임 본체 (코드와 이미지가 하나의 파일에 포함)
audio/
  title.mp3  intro.mp3
  st1.mp3 … st5.mp3
  ed1.mp3 … ed3.mp3
  gameover.mp3  rank.mp3
```

`audio/` 폴더가 없으면 BGM 대신 코드로 합성한 음악이 재생되며, 게임 진행에는 문제가 없습니다. 효과음은 모두 코드로 합성합니다(Web Audio).

## 실행 방법

1. `index.html`과 `audio/` 폴더를 같은 위치에 둡니다.
2. 웹 서버로 엽니다. (파일을 바로 열면 브라우저 정책 때문에 BGM을 불러오지 못할 수 있습니다.)
   ```
   python3 -m http.server 8000
   ```
   브라우저에서 `http://localhost:8000` 을 엽니다.
3. 화면을 클릭하거나 터치하면 시작합니다. (소리가 나옵니다.)
